# Undertone documentation

Undertone is a music server for Jellyfin apps that has nothing inside it: everything it does comes from connection
files.

| Page | For |
|---|---|
| [Getting started](getting-started.md) | Running the server, accounts, choosing a catalog, adding connections, connecting an app, importing playlists |
| [How it works](how-it-works.md) | What happens when you search and when you press play, and how files are matched to songs |
| [Writing connections](connections.md) | The connection file format: every block and every field |

The [server](../undertone/) and [ready-made connections](../undertone-connections/) are included in this repository.
